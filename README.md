# My Website

Academic website for Leyao (Lia) Tan, Ph.D. student in Quantitative Marketing at the University of British Columbia.

## Local development

From the repository root:

```sh
python3 -m http.server 8000 --directory site --bind 127.0.0.1
```

Open `http://127.0.0.1:8000/`. The homepage and Fun Facts page share `site/assets/styles.css` and `site/assets/site.js`.

## Content

- Homepage: `site/index.html`
- Fun Facts: `site/fun-facts/index.html`
- Typography, colors and layout: `site/assets/styles.css`
- Navigation: `site/assets/site.js`
- Photographs and illustrations: `site/assets/images/`
- Site icons: `site/assets/icons/` and `site/favicon.ico`
